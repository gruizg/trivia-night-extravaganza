# Trivia Night Extravaganza

### Definitions
- Users: a person that is visiting, creating an account, or is logged in
- Host: Any person that is hosting a game of trivia, for the duration of the game
- Player: an individual or team participating in a game of trivia, for the duration of the game.

## MVP

### While logged out
- Users can view 'About', 'Rules', 'Home'
- Users can select to host or join a game of trivia


### While Hosting
- Hosts can view a list of themes to play from
- Hosts can click on a theme and view a lobby showing incoming players, info about the theme
- Hosts can start the trivia at any time from the lobby
- When a game starts, rules are presented
- When a game starts, the host is presented with a list of all player names and numbers
- When a question is presented, a host will see incoming responses in a list and manually mark them as correct or incorrect
- When a question has 1 or more answers, a host can count up the number of correct answers and award the correct amount of points
- When all responses are submitted, the host can reveal the answer and notify players if they were correct or not
- Host can amend a question if requested by player and reasonably justified
- Before halftime or final trivia, the host is presented with an updated list of rankings to announce
- Host will announce final rankings after final trivia
- In the event of a tie in any top 3 placements, the host can present additional tiebreaker questions for the players in question

### While Playing
- Players will be prompted to enter a room code to join
- Players will view a form to enter a name
- When a game starts, rules are presented
- During each question, players will select a number of points to wager, and write their answer to the question open-ended style.
- Players will be notified if their answer is correct after the host reveals the answer
- Players can request to have incorrect responses ameneded and give written justification
- Players will be notified of their ranking before halftime and final trivia
- Players can manually wager points for final trivia
- Players will see their final ranking after host announces


## Stretch*
- Users can create an account and log in

### While Logged In
- Users can create trivia games
- Users are prompted to name and give description of the trivia game
- Users a prompted to fill out three questions at a time
- Halftime and final trivia questions are prompted separately
- Tiebreaker questions are prompted last
- Users can edit trivia games created by themselves

## Stretch

- Users can set their trivia games to be private
- When viewing their own trivia games, users can see statistics on correct:incorrect responses per question, and how often they are amended
- Users can view a list of all public trivia games and click host button from the list to start game
